# RankView

GitHub Pages로 배포할 수 있는 단일 페이지 순위 대시보드입니다.

## 로컬 확인

`index.html`을 브라우저에서 열면 예시 데이터로 화면을 확인할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
3. 배포 브랜치로 `main`, 폴더로 `/(root)`를 선택하고 저장합니다.
4. 안내되는 주소에서 사이트를 확인합니다.

## 데이터 갱신

실제 원본은 [data/ranking.txt](data/ranking.txt)입니다. 같은 형식으로 과거 집계와 최신 집계를 차례로 추가하면 사이트가 최신 목록을 현재 순위로, 그 직전 목록을 비교 기준으로 읽습니다. 항목별 현재 순위·순위 변동·두 집계 시점의 개수 추이가 자동 계산됩니다.
